# Transmogrify (COmanage Registry Plugin)

Transmogrify is a command‑line migration tool bundled as a CakePHP plugin for COmanage Registry PE. It copies and transforms data from a legacy/source Registry schema (cm_… tables) into the PE target schema.

## Documentation

For background, concepts, and Registry-side guidance on transmogrification, see the COmanage documentation:
